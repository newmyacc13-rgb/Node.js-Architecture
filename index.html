Edge-Cache Coalescence

A hybrid invalidation model for the 2026 latency benchmark — where origin shielding, tiered residency, and request coalescence meet at the wire.

01 — The coalescence gap

Request coalescing has been standard practice for a decade: collapse concurrent misses for the same key into a single origin fetch. What changed in 2026 is the residency dimension. Edge nodes no longer hold one cache. They hold a hierarchy — a hot in-memory tier, a warm NVMe tier with direct block-address mapping, and a shielded origin tier with a bounded stale window. Coalescence that ignores residency will hold waiters behind a miss that a warm tier could have served in single-digit microseconds.

The benchmark we care about is p99, not p50. A coalescing window tuned for the median is a window tuned for the wrong distribution. At p99, the cost of a false miss dominates the cost of a short hold.

02 — Dual-path residency

The NVMe-direct path bypasses the page cache entirely, mapping cache objects to contiguous logical block addresses. For prefill-shaped workloads this is not a micro-optimization; it is the difference between a predictable tail and a tail governed by kernel writeback pressure. The page-cache path remains correct for objects under a size threshold where the filesystem’s readahead heuristic still earns its keep.

03 — Invalidation without a stampede

Tag-based invalidation propagates within seconds across the edge network. The failure mode is not propagation latency; it is the burst of revalidations that follows a tag flush. A surrogate-key fan-out without a lease collapses into a thundering herd against the origin. The 2026 default loop is: tag flush → lease grant on first miss → coalesce the remainder behind the lease → serve stale from the shield tier while the lease holder revalidates.

04 — What the tail actually costs

A single stale entry at an edge node can cost a mid-size team most of a debugging day. The cost is not the stale byte — it is the correlated staleness across the surrogate set. When a tag flush fails to fan out to every node that holds a derivative object, the inconsistency is topological, not temporal. The fix is to treat the surrogate key as the unit of truth, not the URL.
